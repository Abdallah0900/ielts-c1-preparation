IELTS C1-Equivalent Preparation

A structured, evidence-based curriculum for preparing learners for IELTS General Training Band 7–8, using CEFR C1 as a language-proficiency reference.

Project Goal

Build a structured learning platform that helps learners progress from approximately B1 level toward C1-level proficiency while preparing for IELTS General Training.

The curriculum is based on:

- Official IELTS public documentation
- IELTS Band Descriptors
- CEFR framework
- Cambridge English resources
- British Council resources
- Oxford Learner's Dictionaries and other reputable language references

Target

- Starting level: B1
- Progression: B1 → B2 → B2+ → C1
- IELTS type: General Training
- Target IELTS Band: 7–8
- CEFR target: C1-equivalent proficiency as an approximate alignment, not an official equivalence

Curriculum

The planned curriculum follows five stages:

1. Foundation Strengthening
2. Skills Development
3. Band 6 → 7 Bridge
4. Band 7 → 8 Bridge
5. Exam Simulation

The curriculum is designed around progressive language development and IELTS skill development rather than memorisation of isolated vocabulary or grammar rules.

IELTS Skills

The platform covers:

- Listening
- Reading
- Writing
- Speaking

Writing preparation focuses on IELTS General Training, including:

- General Training Writing Task 1
- Writing Task 2

Assessment

The platform uses formative assessment and progress tracking.

Automated or AI-generated feedback is intended for learning and practice only.

It does not constitute an official IELTS score.

Official IELTS scores require assessment through an authorised IELTS test provider.
